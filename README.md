### 🏥 Now: Yashfii (AI & Software Engineer)

I'm the sole engineer of the **Yashfii Platform**, a clinical AI platform in production since November 2026:
- an **AI gateway** that meters every model call at its billed cost and routes each feature to a model chosen by evaluation (one switch made the clinical analysis **63% cheaper at the same score**);
- a **tool-calling assistant** that acts through the platform's own APIs, with the user's permissions and a confirmation step;
- **clinical guardrails**, and a **FHIR R4 / HL7 v2** partner API;
- PostgreSQL with row-level security, **815 automated tests** and **48 decision records**.

The repository is private.
